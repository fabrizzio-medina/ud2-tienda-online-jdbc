# Uso de inteligencia artificial

## Herramientas utilizadas
- **Nombre:** ChatGPT y Claude.
- **Forma de uso:** Chat mediante navegador web y aplicación.
- **Uso principal:** Consultas puntuales para resolver dudas de programación, obtener orientación sobre la estructura del proyecto, comprender clases Java y solucionar problemas durante el desarrollo.
- **Grado de utilización:** Uso complementario. La mayor parte del desarrollo, implementación y organización del código se realizó de forma propia.

## Prompts principales

1. Dame ideas de temáticas originales para desarrollar una tienda online en Java utilizando JDBC. Busco algo que tenga suficientes entidades y relaciones para cumplir los requisitos de la práctica.

2. He elegido desarrollar una tienda de componentes y productos tecnológicos. Dame algunas ideas de nombres originales para la aplicación y el negocio.

3. Ayúdame a identificar qué clases Java podría necesitar para organizar el proyecto siguiendo una arquitectura basada en Model, DAO, Service y DTO.

4. ¿Qué nombres recomendarías para las clases encargadas de gestionar productos, clientes, pedidos, categorías, inventario y pagos? Quiero mantener una nomenclatura clara y coherente.

5. Explícame qué responsabilidad debería tener cada clase dentro de una arquitectura Java por capas y cómo deberían relacionarse entre ellas.

6. ¿Cómo puedo organizar los paquetes de un proyecto Java para separar correctamente la conexión a la base de datos, los modelos, los DAO, los servicios y las excepciones?

7. Explícame cómo funcionan los constructores en Java y cómo puedo inicializar correctamente los atributos de mis clases de modelo.

8. ¿Cómo puedo implementar una conexión JDBC con MySQL utilizando DriverManager? Explícame también cómo organizarla para reutilizarla desde diferentes DAO.

9. ¿Cómo puedo utilizar PreparedStatement para insertar, actualizar, eliminar y consultar registros sin concatenar directamente los valores en las consultas SQL?

10. Explícame cómo recuperar los identificadores autogenerados por MySQL después de insertar un registro y utilizarlos para relacionar otras tablas.

11. ¿Cómo puedo realizar consultas SQL con JOIN para obtener información relacionada de varias tablas y transformarla en objetos Java mediante ResultSet?

12. ¿Cómo puedo utilizar BigDecimal en Java para gestionar los precios de los productos y evitar problemas de precisión con los números decimales?

13. Explícame cómo funcionan las transacciones JDBC y cómo implementar correctamente commit() y rollback() cuando una operación modifica varias tablas.

14. ¿Cómo puedo organizar las excepciones personalizadas para diferenciar errores de negocio, como la falta de stock, de errores técnicos relacionados con JDBC?

15. ¿Cómo puedo utilizar try-with-resources para cerrar correctamente Connection, PreparedStatement y ResultSet y evitar fugas de recursos?

16. Explícame cómo realizar pruebas con JUnit 5 para comprobar que las operaciones de inserción, consulta, modificación y transacciones funcionan correctamente contra una base de datos real.
